    Getting Started Guide

    Follow these steps to connect your media servers to Stremio.

    1
    Create your account & sign in

    Click the avatar icon in the sidebar to register or log in. An account lets you save your config to the cloud and generate your personal Stremio install link.

    2
    Add your Emby or Jellyfin servers

    Go to Servers and click + Add Server. Enter your server URL, API key, and user ID. You can add as many servers as you have — they'll all be bridged together in Stremio.

    💡 Your API key is in Emby/Jellyfin under Dashboard → API Keys.
    3
    Configure your streaming preferences

    Visit Streaming to choose your preferred video quality, audio language, subtitle settings, and stream source priority. Streams are sorted by file size by default — largest = best quality.

    4
    Set up external catalogs (optional)

    In Catalogs you can add Trakt lists, MDBList collections, IMDb RSS feeds, and Letterboxd lists as rows on your Stremio home screen. Requires a free API key from each provider.

    💡 The shuffle button on each row randomises the order every time Stremio refreshes.
    5
    Get your API keys

    Head to API Keys to enter your Trakt Client ID, MDBList API key, and any other integration keys. These are stored encrypted and never shared.

    6
    Install into Stremio

    Go to Install. Copy your personal /u/<token>/manifest.json URL into Stremio's addon search bar, or scan the QR code on mobile. Do not share legacy encoded URLs — they expose API keys.

    💡 Your token link stays the same; settings sync automatically when you save changes.
    7
    Monitor your servers

    Your Dashboard shows uptime bars and response-time charts on each server card. The Ping test lets you compare latency from your browser vs the addon server.

    8
    Need help?

    Open a Support Ticket and we'll assist you. Include your server type (Emby/Jellyfin), what you're seeing in Stremio, and any error messages.
